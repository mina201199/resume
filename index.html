01 / 個人專案・AI 應用整合・本機 MVP

PredictFix AI智慧維修助理

把維修知識查找、資格派工與排查驗收，整合成可追溯的工作流程。

  • 應用整合：以本機 Gemma 搭配手冊／案例 RAG，整合 FastAPI、SQLAlchemy 與 TF-IDF／BM25 檢索；後端驗證來源段落，讓排查依據可追溯。
  • 流程與權限：串接資格派工、主管核准與驗收，未達條件即由後端阻止結案；實作角色權限、版本檢查與冪等請求，派工時重驗資格與容量。
  • 測試與交付：161 項自動化測試與 45／45 項 AI／API 安全檢查通過，並以 CI 驗證容器及 PostgreSQL 情境、重啟保存與備份還原。
  • 微調評估：Gemma QLoRA 完全正確率由 18% 提升至 42%，但 Recall 下降，評估後未導入現用模型。

本機 MVP；公開展示為虛構流程與實機影片，尚未完成工廠現場驗收。

02 / 團隊專案・SQL 與語意雙重守門

PowerQuery TW台電智慧查詢

將中文問題轉為受限查詢，讓查詢結果、SQL 與資料限制都能被檢查。

  • 個人分工：團隊專案（fork 自 lee851104/text2sql_project）的個人延伸，本人負責線上評測工具與離線問法擴充。
  • 意圖解析與服務：解析中文意圖產生 SQL，未知問法可拒答或澄清，並支援選擇性串接 OpenAI；整合 CSV 清理、SQLite 語意層與中文規則路由，透過 FastAPI 提供 SQL、執行紀錄、表格與圖表。
  • 查詢防護：執行前驗證 SQL AST、資料表／欄位白名單、唯讀權限及筆數限制；檢查單位、時間與資料粒度語意，阻擋跨日功率加總成電量等錯誤。
  • 離線評測：以離線規則模式評測，固定題組通過 60／60 題查詢執行、15／15 題 SQL 攻擊與 45／45 題語意陷阱；未宣稱線上 LLM 準確率。

離線展示可免 API key；線上模型可選配，目前未提供真實 LLM 準確率。
