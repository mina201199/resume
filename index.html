01 / AI 應用整合・本機 MVP

PredictFix AI智慧工廠維修 Copilot

把維修知識查找、資格派工與排查驗收，整合成可追溯的工作流程。

  • 應用整合：開發維修 Copilot，整合 FastAPI、SQLAlchemy、TF-IDF／BM25 檢索與本機 LLM，串接手冊查詢、資格派工、排查驗收及主管審核。
  • 可靠性設計：實作來源引用驗證、角色權限、版本檢查與冪等請求；派工時重驗資格與容量，驗收未完成時由後端阻擋提交。
  • 測試與交付：建立 161 項自動化測試通過的驗證紀錄，並以 CI 驗證容器及 PostgreSQL 情境、重啟保存與備份還原。

本機 MVP；公開展示為虛構流程與實機影片，尚未完成工廠現場驗收。

02 / 自然語言查詢・SQL 與語意雙重守門

PowerQuery TW台電資料 Text2SQL 查詢系統

將中文問題轉為受限查詢，讓查詢結果、SQL 與資料限制都能被檢查。

  • 資料與服務：整合 CSV 清理、SQLite 語意層、中文規則路由與可選 LLM adapter，透過 FastAPI 提供 SQL、執行紀錄、表格與圖表。
  • 查詢防護：實作 SQL AST 唯讀驗證、資料表／欄位允許清單及筆數限制；檢查單位、時間與資料粒度，阻擋跨日功率加總成電量等語意錯誤。
  • 離線評測：以離線規則模式評測，固定題組通過 60／60 題查詢執行、15／15 題 SQL 攻擊與 45／45 題語意陷阱；未宣稱線上 LLM 準確率。

離線展示可免 API key；線上模型可選配，目前未提供真實 LLM 準確率。

03 / 團隊專案・個人延伸開發

Life House安居指數

以桃園交通事故資料呈現住家周邊 500 公尺步行生活圈的歷史風險。

  • 競賽與協作：參與住宅周邊行人事故分析平台，團隊自 160 組參賽隊伍中進入前 10 強；個人功能貢獻有已合併 PR 可追溯。
